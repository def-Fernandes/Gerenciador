# Gerenciador de Produção 
Esse código se trata de um projeto de construção de um software que seja tanto uma calculadora de orçamento, quanto o local de anotação dos pedidos que levam diretamente para o site Trello.

Nesse projeto escrito em Python, foram usadas as bibliotecas: Tkinter (interface gráfica), requests (requisicões da API do Trello), os (para usar pastas), dotenv (para deixar as constantes chave/token/id da lista) e sys (padronizar o caminho da imagem).
